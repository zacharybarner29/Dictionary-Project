# Dictionary Project
I made a program that can use values and return calculations from a dictionary containing statistics from the 2025-26 Chicago Bears players.

##  Calculations
1. Comparing Statistics
   - The user inputs two of the same statistics from two different players, and it finds the difference and percent change between them
3. Finding the greatest statistic within a position
   - The program loops through each specified statistic for all the players in a specified position
5. Calculating the "player score" (average of all their statistics combined)
   - The user inputs the player, and the program adds up the value from each statstic and divides it by the number of statistics to get the average
  
## Challenge I Ran Into
When the user wanted to add a new player, they needed to add all of their statistics, but different positions have different statistics. I solved this by showing the user the available statistics based on the position they inputted. 

## What I'd Improve With More Time
I would have made the program's outputs more visually appealing and given the user their available options for each calculation, rather than assuming they knew them.
